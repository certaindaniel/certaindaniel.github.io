TinyGtask — 隐私政策

最后更新：2026 年 11 月 2 日

TinyGtask 是 Google Tasks 的 macOS 客户端，没有自己的服务器，数据直接在你的 Mac 与 Google 之间传输。

Google 账号数据

TinyGtask 会向 Google 请求以下权限：

• Google Tasks（auth/tasks）：查看、创建、编辑、整理和删除你的任务与列表。

• 电子邮件地址与基本个人资料（userinfo.email、userinfo.profile）：显示当前登录的账号。

这些数据只用于提供上述功能，不会出售、分享，也不会发送到 Google 以外的服务器。

Google API 服务用户数据政策

TinyGtask 对从 Google API 获取的信息的使用及向其他 App 的传输，将遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

存储在 Mac 上的数据

• 登录凭证存储在 macOS 钥匙串。

• 任务从 Google 加载后，只在 App 运行时保留在内存中。TinyGtask 没有离线任务数据库。

• 偏好设置存储在本地 App 设置中。

• 如果你允许通知，提醒会通过 macOS 在本地安排。

存储在 Google 账号的数据

任务留在 Google Tasks。由于 Google Tasks API 没有对应字段，TinyGtask 会把优先级和提醒时间以文字存入任务备注，其他 Google Tasks App 可能会显示这些文字。

第三方服务

TinyGtask 没有分析、广告或跟踪 SDK，只连接 Google 的登录与 API 服务。

你的控制权

在 App 中退出登录，即可清除钥匙串里的登录凭证。你也可以到 Google 账号权限页面撤销访问权限。你的任务仍会留在 Google 账号。

儿童

TinyGtask 是通用的效率 App，并非面向未满 13 岁的儿童。
