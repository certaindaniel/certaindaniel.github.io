TinyGtask — 支持与常见问题

最后更新：2026 年 11 月 2 日

常见问题

Q1: TinyGtask 会把任务存到服务器吗？

不会。TinyGtask 没有自己的服务器，直接与 Google 连接，任务都留在你的 Google 账号。

Q2: 可以离线使用吗？

不可以。TinyGtask 通过 Google Tasks API 读取和保存任务，需要网络连接。

Q3: 为什么不能删除来自 Google 文档或 Chat 的指派任务？

通过 Google Tasks API 删除时，文档或 Chat 里的原始任务也会一起删除。请先到任务来源打开它，并在那里取消指派。

Q4: 如何退出登录或移除访问权限？

在 App 中选择退出登录。若要完全移除访问权限，请到 Google 账号权限页面撤销 TinyGtask。

Q5: 为什么没有收到提醒？

请到 macOS 系统设置 > 通知允许 TinyGtask。只有日期的任务，要在当地时间 09:00 前完成安排，才会有 09:00 摘要；有指定提醒时间的任务则按该时间提醒。
