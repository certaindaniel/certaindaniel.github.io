TinyGtask

Google Tasks 的原生 macOS 菜单栏 App。

从 Mac 菜单栏查看和添加 Google Tasks，也能打开完整窗口管理列表、标签、子任务和备注。TinyGtask 直接连接你的 Google 账号，没有自己的服务器。

TinyGtask 会把任务存到服务器吗？

不会。TinyGtask 没有自己的服务器，直接与 Google 连接，任务都留在你的 Google 账号。

可以离线使用吗？

不可以。TinyGtask 通过 Google Tasks API 读取和保存任务，需要网络连接。

为什么不能删除来自 Google 文档或 Chat 的指派任务？

通过 Google Tasks API 删除时，文档或 Chat 里的原始任务也会一起删除。请先到任务来源打开它，并在那里取消指派。
