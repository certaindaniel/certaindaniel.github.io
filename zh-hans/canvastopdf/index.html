Web to PPT (Editable)

用 AI 做的 HTML 幻灯片，一键变成「真正可编辑」的 PowerPoint，100% 本地处理。

用 AI 做的 HTML 幻灯片，一键变成「真正可编辑」的 PowerPoint——文字、图形都是原生对象，不是截图。100% 本地处理，买断制。

隐私政策
  • 粘贴或导入 AI 生成的 HTML 幻灯片
  • 文字、图形、表格都是可编辑的原生对象，不是截图
  • 导出为原生 PowerPoint (.pptx)
  • 也能导出高画质 16:9 幻灯片 PDF
  • 100% 本地处理，内容不上传
  • 买断制，无订阅

这个 App 需要网络连接吗？

不需要——转换、渲染与导出都在你的 Mac 上完成。只有当你自己的 HTML 内容引用外部资源（如图片、字体）时才会用到网络。

我的内容会被上传到哪里吗？

不会。你输入的 HTML/React 内容与导出的 PDF/PPTX 文件都留在你的设备上，不会传送到任何服务器。

这是订阅制吗？

不是。网页转 PPT (可编辑) 是 Mac App Store 一次性付费购买，没有订阅也没有内购。

有分析工具或广告吗？

没有。App 不含任何第三方分析或广告 SDK。
