TinyKanban — 隐私政策

最后更新：2026 年 11 月 28 日

TinyKanban 是 Google Tasks 的 macOS 客户端，没有自己的服务器，数据直接在你的 Mac 与 Google 之间传输。开发者看不到你的任务或账号数据。

TinyKanban 访问的 Google 用户数据

登录时，TinyKanban 会向 Google 请求以下权限：

• Google Tasks（https://www.googleapis.com/auth/tasks）：你的任务列表与任务，包括标题、备注、截止日期、完成状态和子任务。

• 电子邮件地址（userinfo.email）与基本个人资料（userinfo.profile）：你的 Google 账号电子邮件、名称和头像。

TinyKanban 不会访问其他 Google 数据。

TinyKanban 如何使用 Google 用户数据

• Google Tasks 数据只用于在看板上显示你的任务，以及执行你要求的更改：创建、编辑、移动、完成和删除任务与列表。

• 电子邮件地址与基本个人资料只用于显示当前登录的是哪个 Google 账号。

TinyKanban 不会把 Google 用户数据用于广告，不会用于训练 AI 或机器学习模型，也不会让任何人阅读。

分享、传输与披露

TinyKanban 不会出售、分享、传输或披露 Google 用户数据给任何第三方。数据只在你的 Mac 与 Google 服务器之间传输。开发者没有服务器，所以从不会收到你的数据，也没有数据可以披露。

Google API 服务用户数据政策

TinyKanban 对从 Google API 获取的信息的使用及向其他 App 的传输，将遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

数据保护方式

• 你在 Google 自己的登录页登录，TinyKanban 看不到你的 Google 密码。

• 所有对 Google 的请求都使用加密的 HTTPS 连接。

• 登录凭证存储在 macOS 钥匙串，由 macOS 加密保护。

• 任务只在 App 运行时保留在内存中。TinyKanban 不会把任务写入磁盘，也没有离线任务数据库。

• 偏好设置（例如窗口与显示设置）存储在本地 App 设置中，不含 Google 用户数据。

• 如果你允许通知，提醒会通过 macOS 在本地安排。

数据保留与删除

• 内存中的任务数据会在你退出 TinyKanban 时清除。

• 登录凭证会留在钥匙串，直到你退出登录；退出登录时立即删除。

• 你可以随时到 Google 账号权限页面撤销 TinyKanban 的访问权限。撤销后，TinyKanban 就无法再读取或更改你的数据。

• 任务留在 Google Tasks，由 Google 保存到你删除为止。由于 Google Tasks API 没有对应字段，TinyKanban 会把优先级、提醒时间和看板状态以文字存入任务备注，其他 Google Tasks App 可能会显示这些文字。要移除，请编辑备注或删除任务。

• 删除 App 会一并移除它的本地设置。TinyKanban 不会在其他地方保留你的数据副本。

第三方服务

TinyKanban 没有分析、广告或跟踪 SDK，只连接 Google 的登录与 API 服务。

儿童

TinyKanban 是通用的效率 App，并非面向未满 13 岁的儿童。
