TinyKanban

在 Mac 上把 Google Tasks 变成看板。

把 Google Tasks 拖到 To Do、In Progress 和 Done。卡片移到 Done，Google Tasks 里的任务也会完成。TinyKanban 也提供菜单栏快速访问，并直接连接你的 Google 账号，没有自己的服务器。

TinyKanban 会把任务存到服务器吗？

不会。TinyKanban 没有自己的服务器，直接与 Google 连接，任务都留在你的 Google 账号。

可以离线使用吗？

不可以。TinyKanban 通过 Google Tasks API 读取和保存任务，需要网络连接。

为什么不能删除来自 Google 文档或 Chat 的指派任务？

通过 Google Tasks API 删除时，文档或 Chat 里的原始任务也会一起删除。请先到任务来源打开它，并在那里取消指派。
