Q-Dir

A lightweight macOS file manager — multi-pane, quick preview, tags, SFTP.

A lightweight macOS file manager built for speed — multi-pane browsing, Quick Look, Finder tag sync, and SFTP support.

View on the Mac App Store Privacy Policy
  • Multi-pane list & grid view
  • Quick Look and fast file preview
  • Finder tag sync
  • Drag & drop file operations
  • Built-in SFTP support

Does Q-Dir need an internet connection?

No. All file browsing and management work entirely offline.

Is my data uploaded anywhere?

No. Q-Dir has no server — everything is processed and stored on your Mac. If you use SFTP, credentials are stored in the macOS Keychain and the connection goes directly to the server you specify.

Is this a subscription?

No. Q-Dir is a one-time purchase on the Mac App Store, no subscription, no additional in-app purchases.

Does Q-Dir show ads or track me?

No. Q-Dir has no analytics, advertising, or tracking SDKs of any kind.
