TinyKanban

在 Mac 上把 Google Tasks 變成看板。

把 Google Tasks 拖到 To Do、In Progress 和 Done。卡片移到 Done，Google Tasks 裡的任務也會完成。TinyKanban 也提供選單列快速存取，並直接連線到你的 Google 帳號，沒有自己的伺服器。

隱私權政策 支援與常見問題
  • 任何 Google Tasks 清單都能用看板：在 To Do、In Progress、Done 之間拖曳卡片
  • 把多份清單放在一起，依狀態分組
  • 選單列快速查看與新增
  • 今天、逾期、Inbox、Forecast 和已加星號檢視
  • #標籤與側邊欄篩選
  • 子任務、Markdown 筆記、優先級和提醒時間
  • 用 Cmd+F 跨清單搜尋
  • 解析英文、中文和日文的日期時間

TinyKanban 會把任務存到伺服器嗎？

不會。TinyKanban 沒有自己的伺服器，直接與 Google 連線，任務都留在你的 Google 帳號。

可以離線使用嗎？

不行。TinyKanban 透過 Google Tasks API 讀取和儲存任務，需要網路連線。

為什麼不能刪除來自 Google 文件或 Chat 的指派任務？

透過 Google Tasks API 刪除時，文件或 Chat 裡的原始任務也會一起刪除。請先到任務來源開啟它，並在那裡解除指派。
