TinyKanban — 隱私權政策

最後更新：2026 年 11 月 2 日

TinyKanban 是 Google Tasks 的 macOS 用戶端，沒有自己的伺服器，資料直接在你的 Mac 與 Google 之間傳輸。

Google 帳號資料

TinyKanban 會向 Google 要求以下權限：

• Google Tasks（auth/tasks）：查看、建立、編輯、整理和刪除你的任務與清單。

• 電子郵件地址與基本個人資料（userinfo.email、userinfo.profile）：顯示目前登入的帳號。

這些資料只用來提供上述功能，不會出售、分享，也不會傳送到 Google 以外的伺服器。

Google API 服務使用者資料政策

TinyKanban 對於從 Google API 取得之資訊的使用及傳輸至其他 App，將遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

儲存在 Mac 上的資料

• 登入憑證儲存在 macOS 鑰匙圈。

• 任務從 Google 載入後，只在 App 執行時保留在記憶體中。TinyKanban 沒有離線任務資料庫。

• 偏好設定儲存在本機 App 設定中。

• 如果你允許通知，提醒會透過 macOS 在本機排程。

儲存在 Google 帳號的資料

任務留在 Google Tasks。由於 Google Tasks API 沒有對應欄位，TinyKanban 會把優先級、提醒時間和看板狀態以文字存進任務筆記，其他 Google Tasks App 可能會顯示這些文字。

第三方服務

TinyKanban 沒有分析、廣告或追蹤 SDK，只連線到 Google 的登入與 API 服務。

你的控制權

在 App 中登出，即可清除鑰匙圈裡的登入憑證。你也可以到 Google 帳號權限頁面撤銷存取權。你的任務仍會留在 Google 帳號。

兒童

TinyKanban 是一般用途的生產力 App，並非以未滿 13 歲的兒童為對象。
