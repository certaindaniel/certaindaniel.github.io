TinyKanban — 隱私權政策

最後更新：2026 年 11 月 28 日

TinyKanban 是 Google Tasks 的 macOS 用戶端，沒有自己的伺服器，資料直接在你的 Mac 與 Google 之間傳輸。開發者看不到你的任務或帳號資料。

TinyKanban 存取的 Google 使用者資料

登入時，TinyKanban 會向 Google 要求以下權限：

• Google Tasks（https://www.googleapis.com/auth/tasks）：你的任務清單與任務，包括標題、筆記、到期日、完成狀態和子任務。

• 電子郵件地址（userinfo.email）與基本個人資料（userinfo.profile）：你的 Google 帳號電子郵件、名稱和大頭貼。

TinyKanban 不會存取其他 Google 資料。

TinyKanban 如何使用 Google 使用者資料

• Google Tasks 資料只用來在看板上顯示你的任務，以及執行你要求的變更：建立、編輯、移動、完成和刪除任務與清單。

• 電子郵件地址與基本個人資料只用來顯示目前登入的是哪個 Google 帳號。

TinyKanban 不會把 Google 使用者資料用於廣告，不會用來訓練 AI 或機器學習模型，也不會讓任何人閱讀。

分享、傳輸與揭露

TinyKanban 不會出售、分享、傳輸或揭露 Google 使用者資料給任何第三方。資料只在你的 Mac 與 Google 伺服器之間傳輸。開發者沒有伺服器，所以從不會收到你的資料，也沒有資料可以揭露。

Google API 服務使用者資料政策

TinyKanban 對於從 Google API 取得之資訊的使用及傳輸至其他 App，將遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

資料保護方式

• 你在 Google 自己的登入頁登入，TinyKanban 看不到你的 Google 密碼。

• 所有對 Google 的請求都使用加密的 HTTPS 連線。

• 登入憑證儲存在 macOS 鑰匙圈，由 macOS 加密保護。

• 任務只在 App 執行時保留在記憶體中。TinyKanban 不會把任務寫入磁碟，也沒有離線任務資料庫。

• 偏好設定（例如視窗與顯示設定）儲存在本機 App 設定中，不含 Google 使用者資料。

• 如果你允許通知，提醒會透過 macOS 在本機排程。

資料保留與刪除

• 記憶體中的任務資料會在你結束 TinyKanban 時清除。

• 登入憑證會留在鑰匙圈，直到你登出；登出時立即刪除。

• 你可以隨時到 Google 帳號權限頁面撤銷 TinyKanban 的存取權。撤銷後，TinyKanban 就無法再讀取或變更你的資料。

• 任務留在 Google Tasks，由 Google 保存到你刪除為止。由於 Google Tasks API 沒有對應欄位，TinyKanban 會把優先級、提醒時間和看板狀態以文字存進任務筆記，其他 Google Tasks App 可能會顯示這些文字。要移除，請編輯筆記或刪除任務。

• 刪除 App 會一併移除它的本機設定。TinyKanban 不會在其他地方保留你的資料副本。

第三方服務

TinyKanban 沒有分析、廣告或追蹤 SDK，只連線到 Google 的登入與 API 服務。

兒童

TinyKanban 是一般用途的生產力 App，並非以未滿 13 歲的兒童為對象。
