Web to PPT (Editable)

用 AI 做的 HTML 簡報，一鍵變成「真正可編輯」的 PowerPoint，100% 本機處理。

用 AI 做的 HTML 簡報，一鍵變成「真正可編輯」的 PowerPoint——文字、圖形都是原生物件，不是截圖。100% 本機處理，買斷制。

在 Mac App Store 查看 隱私權政策
  • 貼上或匯入 AI 生成的 HTML 簡報
  • 文字、圖形、表格都是可編輯的原生物件，不是截圖
  • 匯出成原生 PowerPoint (.pptx)
  • 也能匯出高畫質 16:9 投影片 PDF
  • 100% 本機處理，內容不上傳
  • 買斷制，無訂閱

這個 App 需要網路連線嗎？

不需要——轉換、渲染與匯出都在你的 Mac 上完成。只有當你自己的 HTML 內容引用外部資源（如圖片、字型）時才會用到網路。

我的內容會被上傳到哪裡嗎？

不會。你輸入的 HTML/React 內容與匯出的 PDF/PPTX 檔案都留在你的裝置上，不會傳送到任何伺服器。

這是訂閱制嗎？

不是。網頁轉 PPT (可編輯) 是 Mac App Store 單次付費購買，沒有訂閱也沒有內購。

有分析工具或廣告嗎？

沒有。App 不含任何第三方分析或廣告 SDK。
