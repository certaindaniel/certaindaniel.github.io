TinyGtask

Google Tasks 的原生 macOS 選單列 App。

從 Mac 選單列查看與新增 Google Tasks，也能開啟完整視窗管理清單、標籤、子任務和筆記。TinyGtask 直接連線到你的 Google 帳號，沒有自己的伺服器。

TinyGtask 會把任務存到伺服器嗎？

不會。TinyGtask 沒有自己的伺服器，直接與 Google 連線，任務都留在你的 Google 帳號。

可以離線使用嗎？

不行。TinyGtask 透過 Google Tasks API 讀取和儲存任務，需要網路連線。

為什麼不能刪除來自 Google 文件或 Chat 的指派任務？

透過 Google Tasks API 刪除時，文件或 Chat 裡的原始任務也會一起刪除。請先到任務來源開啟它，並在那裡解除指派。
