TinyGtask — 支援與常見問題

最後更新：2026 年 11 月 2 日

常見問題

Q1: TinyGtask 會把任務存到伺服器嗎？

不會。TinyGtask 沒有自己的伺服器，直接與 Google 連線，任務都留在你的 Google 帳號。

Q2: 可以離線使用嗎？

不行。TinyGtask 透過 Google Tasks API 讀取和儲存任務，需要網路連線。

Q3: 為什麼不能刪除來自 Google 文件或 Chat 的指派任務？

透過 Google Tasks API 刪除時，文件或 Chat 裡的原始任務也會一起刪除。請先到任務來源開啟它，並在那裡解除指派。

Q4: 如何登出或移除存取權？

在 App 中選擇登出。若要完全移除存取權，請到 Google 帳號權限頁面撤銷 TinyGtask。

Q5: 為什麼沒有收到提醒？

請到 macOS 系統設定 > 通知允許 TinyGtask。只有日期的任務，要在當地時間 09:00 前完成排程，才會有 09:00 摘要；有指定提醒時間的任務則依該時間提醒。
